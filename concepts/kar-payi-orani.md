# Kâr Payı Oranı

[[katilim-bankaciligi]]'nda **faiz yerine** kullanılan, finansman işlemine konu
olan mal veya hizmet üzerinden oluşan kâr payı oranı (şartname 5.5, s.9).

- Çıkarılması beklenen **en kritik finansal bilgilerden** biridir; model farklı
  ifade biçimlerini doğru yorumlamalıdır: "%2,05 kâr payı oranı", "avantajlı kâr
  payı fırsatı", "özel oranlı finansman", "düşük maliyetli finansman"
  (şartname 5.2, s.7).
- Aynı değer farklı yazılabilir (%2,05 / % 2.05 / 2.05 %) → normalize edilmeli,
  bkz. [[veri-normalizasyonu]] ve [[farkli-ifade-bicimleri]].
- Karşılaştırma kriterlerinde "En Düşük Kâr Payı Oranı" yer alır (şartname 5.7,
  s.10) → [[urun-karsilastirma]].

İlgili diğer terimler: finansman maliyeti, katılım fonu, masrafsız finansman,
avantajlı finansman (şartname 5.5).

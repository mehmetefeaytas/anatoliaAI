# Web Scraping (Veri Toplama)

Katılım bankalarının resmî web sitelerindeki ürün ve kampanya metinlerinin
otomatik toplanması tekniği (şartname 5.1, s.6).

- Veri seti, **python tabanlı veri toplama araçları/kütüphaneleri, web scraping
  yöntemleri** veya **manuel toplama** ile elde edilebilir (şartname 5.1).
- Kapsam: [[bddk]] listesindeki tüm katılım bankaları → [[katilim-bankalari]].
- Toplama yaklaşımı [[python-tabanli-veri-toplama]] kararıyla netleşir.
- Çıktı: ham metinler → [[veri-on-isleme]] → [[bilgi-cikarimi]].

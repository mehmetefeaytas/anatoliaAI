# Metin Sınıflandırma

Kampanya metinlerinin içeriklerine göre belirli kategorilere ayrılması
(şartname 5.4, s.8). [[nlp]] çözümünün ana yeteneklerinden biri.

Belirlenmesi beklenen örnek **kampanya türleri** için bkz. [[kampanya-turleri]]:
Finansman / İhtiyaç / Konut / Taşıt Finansmanı, Kart Kampanyası, Alışveriş Puanı,
Yeni Müşteri, Yatırım Ürünü kampanyaları.

- Sınıflandırma farklı NLP yöntemleriyle (kural tabanlı, model tabanlı vb.)
  yapılabilir (şartname 5.4).
- Ayrıca model, [[katilim-bankaciligi]] terminolojisindeki kavramları da doğru
  sınıflandırabilmelidir (şartname 5.5, s.8).

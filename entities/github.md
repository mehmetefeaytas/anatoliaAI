# GitHub

Proje kodu, veri seti ve dokümantasyonun açık kaynak olarak paylaşılacağı kod
deposu platformu. Anatolia AI teslimlerinin merkezi.

- Kod, veri kümeleri ve bileşenler GitHub'da **açık lisansla** (Apache, MIT, GNU
  vb.) erişilebilir olmalıdır; nihai teslim **Apache 2.0** iledir (şartname s.17).
- Yüklemede **"BilisimVadisi2026"** etiketi ve [[turkiye-acik-kaynak-platformu]]
  etiketlenmesi zorunludur (şartname s.18).
- Depo şunları içermelidir: (1) bağımlılıkların tam listesi, (2) çalıştırma
  adımları, (3) veri setine herkese açık indirme bağlantısı (şartname s.18).
- Geliştirmeler **en az haftalık** olarak yüklenmelidir; GitHub organizasyonu
  ("create an organization") ile proje tanımı yapılabilir.
- Sunum materyali de GitHub hesabına yüklenmek zorundadır (şartname s.19).

# Türkiye Açık Kaynak Platformu

Yarışma sonunda tüm kaynak kodların, veri kümelerinin ve diğer bileşenlerin
**Apache License 2.0** ile paylaşılacağı resmî [[github]] hesabını işleten
platform.

- Yarışmacılar, yarışma bitiş tarihinde projelerini Türkiye Açık Kaynak Platformu
  GitHub hesabında Apache 2.0 ile yayımlamayı kabul eder (şartname s.17).
- GitHub yükleme sürecinde **"BilisimVadisi2026"** etiketi ve Türkiye Açık Kaynak
  Platformu etiketlenmesi zorunludur (şartname s.18).
